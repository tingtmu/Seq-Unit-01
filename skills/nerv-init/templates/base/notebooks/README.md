# notebooks/

## Purpose

Exploration and figure drafting. Notebooks are not part of the reproducible pipeline.

## Conventions

- Name notebooks `NN-short-topic` (e.g. `01-qc-overview`).
- Read from `results/` or `data/processed/`; never write to `data/raw/`.
- When an analysis becomes final, move the code into `scripts/` and call it from the workflow.
- Clear large outputs before committing.
